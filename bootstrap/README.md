# Bootstrap scripts

## Назначение

Эта директория содержит **bootstrap-скрипты** для первоначальной подготовки
чистого Ubuntu Server к работе с Infrastructure as Code (IaC).

Bootstrap — это **одноразовый этап**, который:
- подготавливает операционную систему,
- устанавливает базовые инструменты (Docker, Git и т.д.),
- **НЕ поднимает приложения или инфраструктурные сервисы**.

После выполнения bootstrap сервер считается готовым
для развёртывания core-infra через Docker Compose.

---

## Что такое bootstrap (важно понять)

Bootstrap — это **не инфраструктура** и **не IaC**.

Bootstrap:
- выполняется **один раз на новой ВМ**,
- может выполняться вручную,
- не предназначен для повторных запусков,
- не должен разрастаться со временем.

Infrastructure as Code начинается **ПОСЛЕ bootstrap**.
