# Infrastructure documentation

Данная директория содержит документацию по инфраструктуре,
которая **не описывается напрямую в IaC**, но является
критически важной для эксплуатации и сопровождения сервера.

## Что здесь описывается

- настройки операционной системы;
- политики доступа;
- сетевые договорённости;
- принципы жизненного цикла сервера.

## Что здесь НЕ описывается

- docker-compose сервисы;
- Gitea / CI / proxy;
- frontend / backend приложения.

Эти компоненты описываются в соответствующих IaC-репозиториях.
